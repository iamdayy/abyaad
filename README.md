# Abyaad

Website brand / toko fashion **Abyaad** (bahasa Arab: putih).

**Live:** https://abyaad.me

## Fitur

- Hero section
- Panduan ukuran (SizeGuide)
- Cerita brand
- Daftar produk dan harga
- FAQ dengan structured data SEO
- Newsletter
- Halaman kontak, privacy policy, shipping, dan terms of service

## Tech Stack

Astro 5, React 18, Tailwind CSS 3, `@astrojs/react`, `@astrojs/sitemap`, `astro-cloudinary` (gambar), `lucide-react`, TypeScript.

## Cara Menjalankan

```bash
npm install
npm run dev      # astro dev
npm run build    # astro build
npm run preview  # astro preview
npm run check    # astro check
```

## Struktur

```
src/
  pages/       # Halaman: index, contact, privacy, dan lainnya
  components/  # Komponen Astro / React
  assets/      # Aset gambar
```
